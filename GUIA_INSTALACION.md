# Guia de instalacion KatHub + KatPlugins

## 1. Instalar KatHub

1. Descarga la ultima version desde GitHub Releases:
   - https://github.com/PaJauKat/kathub-go/releases
   - Descarga `KatHub_Setup.exe`
2. Al ejecutarlo, Windows mostrara una advertencia de SmartScreen
   (editor desconocido / sin firma). Es normal, el software es independiente:
   - Clic en **Mas informacion**
   - Clic en **Ejecutar de todas formas**
3. Sigue el instalador y abre KatHub.

## 2. Instalar KatPlugins

1. Ten RuneLite instalado y cerrado.
2. Abre KatHub (el propio programa pide actualizar el launcher si hace falta).
3. Pulsa el boton de **Instalar / Actualizar KatPlugins**.
4. Cuando termine, inicia RuneLite y carga la sesion.

Los plugins se instalan en `%USERPROFILE%\.runelite\kat\plugins` y no
interfieren con el RuneLite oficial.
